# 验证协议（证据细则）

原则回顾：**验收门禁是唯一裁判**。无证据 = 未完成。证据的作用是替代人不在场时的"人工确认"。

## 一、按任务类型的最低证据

### 1. 改代码逻辑（后端/纯函数/脚本）

三件套，缺一不可：

```
1. 测试：完整命令 + 输出尾部（含 "N passed" 类统计行）
2. typecheck：tsc / 类型检查命令 + 零错误输出（或无输出）
3. lint：项目 lint 命令 + 无 error（warning 可留，简报注明）
```

- 项目没有现成验收命令时，**先找**：`package.json` scripts、`Makefile`、`justfile`、`pytest.ini`、`pyproject.toml`。
- 一个都没有 → 用本目录 §三 的"验收命令发现/补齐"流程。

### 2. 改 UI / 页面 / 前端交互

```
1. 启动 dev server（后台任务，记录端口）
2. 无头 Playwright：导航 → 操作 → 截图，绝对路径存 `night-shift/evidence/<日期>/<用途>-<HHmmss>.png`
3. console 日志无新增 error（用 browser_console_messages 核对）
4. 关掉起过的服务
```

截图文件名带用途，便于晨检按图索骥：`nightshift-fix-sidebar-20261030-0930.png`。

### 3. 修 bug（必须先红后绿）

```
1. 复现：写最小复现用例/操作步骤 → 跑 → 保存【失败输出】（这是红）
2. 修复
3. 再跑同一用例 → 保存【通过输出】（这是绿）
4. 回归：跑全量测试，确认没把别的弄坏
```

只有绿没有红 = 没证明修的是真因（讲话教训：自信指认根因十有八九是幻觉）。

### 4. 重构（不改行为）

```
1. 重构前：全量测试通过的输出
2. 重构后：同一命令再次通过的输出 + diff 概要
```

### 5. 文档/纯文字改动

- 不强制证据；若文档描述的是可运行内容（代码示例、命令），**实际跑一遍**再交付。

## 二、证据怎么"交付"

证据不贴全文（污染上下文），交付三件套 + 两条防伪：

1. **命令**：完整可复现的命令行
2. **统计行**：输出尾部的关键行（如 `Tests: 12 passed, 12 total`）
3. **落盘路径**：`night-shift/evidence/<日期>/<任务>-<用途>-<HHmmss>.log|png`（**原始层，append-only**；`.tmp` 只作中转，不作归档）

**防伪（防复用旧证据）**：① 证据文件**必须带本次运行时间戳**，BRIEF 引用时写"命令 + 执行时间 + 路径"；② **复用旧输出 = 证据造假**，等同隐瞒测试失败，触发 commit 豁免撤销。

晨检时你只需抽查：拿路径 → 打开 → **核对时间戳是否属于本夜**。

## 三、验收命令发现与补齐

**发现顺序**（每个项目开工先做一遍）：

1. `package.json` 的 `scripts.test` / `scripts.check` / `scripts.verify`
2. `Makefile` / `justfile` 的 `test`、`check` 目标
3. `pytest` / `cargo test` / `go test` / `dotnet test` 惯例
4. 都没有 → 按技术栈**拼一条**：

| 技术栈 | 最小验收命令（拼接） |
|---|---|
| TS/Node | `tsc --noEmit && eslint . && vitest run`（按项目实际工具替换） |
| Python | `pytest && mypy . && ruff check .` |
| Rust | `cargo test && cargo clippy -- -D warnings` |
| .NET | `dotnet test` |

**发现的验收命令写进任务总结的"可复用片段"**——第二晚就不用再找。是否固化成项目脚本（`scripts/verify.ps1`），记入 `ESCALATION.md` 升级候选：这是"验收脚本"待办在纯 skill 阶段的替身。

## 四、失败时的处置

- 验证失败 → **这不是禁区问题，是正常工作**：进修复回路，回到任务流程。
- 同一任务连续 3 次换方案仍失败 → blocked，记录每次尝试与失败输出路径，跳下一项。
- 失败原因疑似环境问题（网络、缺系统工具）→ 不装不改环境，blocked + 简报注明。
